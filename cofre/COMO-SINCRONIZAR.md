# Sincronizar o cofre com o GitHub (Obsidian Git, grátis)

1. Instale o Git no computador (git-scm.com) e clone o repositório skills-agentes (ou use o GitHub Desktop).
2. No Obsidian: Abrir pasta como cofre, escolha a pasta `cofre` dentro do clone.
3. Configurações, Plugins da comunidade, ative, Procurar, instale **Obsidian Git** e ative.
4. Nas opções do plugin: auto pull ao abrir e auto commit and push a cada 10 minutos.
5. Os agentes gravam as notas na pasta `cofre/` do repositório; o plugin traz para o seu Obsidian sozinho.

> [!warning] Nunca coloque senhas, chaves ou dados de clientes nas notas.
